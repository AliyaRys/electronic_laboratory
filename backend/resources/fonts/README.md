# Шрифты форм (backend/resources/fonts)

Файлы в этом каталоге — единственные шрифты, которые разрешено подключать
рендереру печатных форм (модуль `backend/src/modules/documents/resources.py`
запрещает любые пути вне этого каталога и любые внешние URL).

| Файл | Назначение | Лицензия |
| --- | --- | --- |
| `DejaVuSans.ttf` | Основной шрифт печатных форм (кириллица + латиница) | Bitstream Vera license + public domain (DejaVu); полный текст — `LICENSE-DejaVuSans.txt` |

SHA-256 каждого файла зафиксирован в `../forms/manifest.json` (поле
`fonts[].sha256`), рендерер проверяет хеш перед подключением шрифта — подмена
файла делает вывод формы невозможным (503), а не молча другим.
