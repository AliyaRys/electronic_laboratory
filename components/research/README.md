# Исследования болезней

`DiseaseResearch.js` — общий компонент необязательных исследований «Инфекционные болезни» и «Незаразные болезни» для страниц создания ВСЭ мяса и продуктов убоя.

Компонент автоматически подключается к существующему блоку `Дополнительные исследования`, добавляет выбранную карточку последней перед кнопками и поддерживает до 10 заболеваний каждого типа. При выборе варианта «Другое…» появляется обязательное открытое поле.

API: `globalThis.VseDiseaseResearch.mount(root)` и `globalThis.VseDiseaseResearch.collect(root)`.

Если конкретный мясной сценарий не использует один из типов болезней, у панели дополнительных исследований можно указать `data-disease-exclude="infectious"` или `data-disease-exclude="noninfectious"`. Несколько ключей перечисляются через запятую. Исключённый тип не создаётся ни как карточка, ни как кнопка добавления; остальные страницы сохраняют полный набор.

## Состояния формы ВСЭ

`VseFormState.js` содержит два общих поведения страниц создания ВСЭ:

- `bindLabSampleField(root)` синхронизирует визуальное состояние поля отправки проб со значением чекбокса;
- `mountFairMarketInvoice({ section, total, storageKey, applied })` показывает неизменяемую пометку «Ярмарка» и удерживает итоговую стоимость на уровне `0 ₽`, если льгота была применена при сверке данных.

Для визуального примера используется `VseFormState.stories.js`, стили принадлежат `vse-form-state.css`.
