# Заключения и вывод документов Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Формировать достоверное заключение по двум основаниям и общий renderer PDF/XLSX.

**Architecture:** Единственная серверная view-model питает preview и PDF; print открывает PDF. Формы/шрифты — контролируемые ресурсы; отчётный renderer принимает только сохранённую матрицу.

**Tech Stack:** WeasyPrint70.0/openpyxl3.1.5, HTML/CSS A4, кириллические fonts.

**Spec:** API-07/08, INPUT-04, ФТ 04, ADR-022. Зависит E/A/I/F.

## Global Constraints

- «Ожидание/несохранённая форма/полный возврат/непригодность блокируют документ».
- «XLSX содержит числа как числа, семь кодов как текст».
- PDF бумага A4, не заявление о стандарте PDF/A; неподтверждённая форма official=false.
- Нет реестра выдачи, e-signature, автоматического исходящего ВСД, статуса вручения/оплаты.

## Review Focus

- Previous ВСЭ неполна: D01 перечисляет отсутствующие реквизиты, без fake local ID.
- Удалена местная при требуемой повторной: D01 не делает fallback на previous.
- Имя с HTML/формулой/очень длинным текстом: D02 безопасно и читаемо выводит его.
- Потеря renderer: D02 не возвращает 200 пустого файла.
- Старый URL после удаления: D01 повторно проверяет основание и отказывает.
