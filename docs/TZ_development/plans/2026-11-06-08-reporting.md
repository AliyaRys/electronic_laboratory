# Показатели и 5-вет Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Реализовать операционные показатели и неизменяемый снимок 5-вет одной лаборатории.

**Architecture:** Preview считается в REPEATABLE READ и возвращается подписанным payload в память формы. Save проверяет подпись/доступ и сохраняет показанное, без повторного расчёта.

**Tech Stack:** Decimal, HMAC-SHA256, PostgreSQL, renderer D02, React.

**Spec:** DATA-05, API-08, ФТ 09, ADR-021/022/023, INPUT-04/05. Зависит E/S/D/C/I/F.

## Global Constraints

- «Максимум один сохранённый отчёт» на type/lab/year/half; только завершённое полугодие.
- Отбор по first_completed_at в Europe/Moscow, полуоткрытые границы.
- «Предельный размер несжатого payload 32 MiB»; до 100000 источников.
- «Сохранить» сохраняет именно показанный снимок; коды семь непустых текстов без масок.

## Review Focus

- Завершение ровно 01.07 00:00: R01 относит во II полугодие.
- Trichinella disease + procedure: R01 не удваивает 168.
- Источник удалён между preview/save: R02 сохраняет прежний показанный payload.
- Перенос токена в другую сессию: R02 отказывает даже тому же actor.
- Удалена последняя строка page2: R03 возвращает на существующую страницу.
