# AUTHZ: полная матрица прикладных действий

Во всех разрешённых ячейках действуют active account, session, CSRF для записи, актуальная область и условие состояния/срока. «Своя область» врача = назначенные лаборатории **и** продукция; заведующего = вся своя лаборатория; администратора = делегированная территория; аналитика = одна выбранная лаборатория Татарстана. Все действия вне таблицы запрещены. Экспорт/счётчик/поиск используют тот же предикат, что чтение. Эта матрица реализуется I02 и используется каждым модулем.

Служебные backup/миграция/метрики/adapter confirm — не дополнительные рабочие роли и недоступны браузерным сеансам. Чтение операции аналитиком не разрешает запускать синхронизацию/гашение; администратор не получает receipt payload по известному UUID операции.
