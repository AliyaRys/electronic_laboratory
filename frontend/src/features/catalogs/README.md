# Справочники каталога (features/catalogs)

Страница «Нормы исследований» (`MethodsEditorPage`) работает на scoped
read model `GET /api/v1/catalogs/methods/context` (DR28, вариант B): backend
возвращает лабораторию, области, разрешённые виды/состояния продукции,
полный перечень VSE-F18–F29, активные нормы и недостающие показатели.
UUID видов/состояний хранятся только внутри — пользователь видит русские
названия, в URL сохраняются код области (`area=meat`) и выбранная пара
для восстанавливаемой ссылки.

## Значения enum-вариантов (DR6)

В справочнике норм (эта папка) значения вариантов показателей передаются
и сохраняются как русские надписи (`label`) из общего реестра
`features/examinations/indicators.ts` — конвенция DR6 для страницы
каталога. В форме ВСЭ (`features/examinations`) те же варианты передаются
кодированными значениями (`value`: `MATCH`, `POSITIVE`, `OTHER`, …).
Не смешивать конвенции: реестр один, а представление значения зависит
от страницы.
