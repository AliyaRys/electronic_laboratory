# Справочники каталога (features/catalogs)

Страница «Нормы исследований» (`MethodsEditorPage`) работает на read model
`GET /api/v1/catalogs/methods/context` (DR31): backend возвращает лабораторию,
категорию «Мясо и мясопродукты», полный перечень VSE-F18–F29, активные нормы
и недостающие показатели. Ключ активной нормы —
`laboratory_id + product_area_code('meat') + indicator_id`: вид/состояние
продукции не выбираются, GUID/UUID не отображаются и не передаются, URL
несёт только код области (`area=meat`).

Композиция страницы (DR36, макет `directory-norms-edit.html`): одна белая
секция «Диапазоны нормы», внутри — числовые строки (`.norm-row`), качественные
блоки (`.boil-*` с квадратными кнопками `＋`/`−` 43×43) и спокойные строки
текстовых исследований. Отдельного списка «Не настроено» и кнопки «Настроить»
нет: ненастроенная числовая строка сразу содержит пустые поля «Норма от»/
«Норма до», качественный блок сразу показывает варианты из реестра; пустая
строка не отправляется и не превращается в нулевой диапазон. Источник,
версия, включённость границ и удаление нормы (FT-CAL-08, Dialog-подтверждение)
сложены в раскрытие «Дополнительные настройки»/«Дополнительные действия»
внутри строки/блока; UUID/GUID и технические коды не показываются.

Обновление DR53 (2026-11-19): контекстные подписи («Лаборатория…»,
«Продукция…», «Категория продукции…») убраны со страниц редакторов;
таблица legacy-тарифов, диагностические карточки (`method-legacy-*`,
unknown-code, fixed/NONE) и кнопки удаления («Удалить тариф»,
«Удалить норму», диалог подтверждения) больше не рендерятся — исторические
строки остаются в БД и аудите, но не показываются пользователю. Сохранённые
`lower_inclusive/upper_inclusive` переживают обычное редактирование (не
перезаписываются значениями по умолчанию); сохранение границ включённости
остаётся серверным по контракту записи. Трихинеллоскопия (VSE-F21) с DR53
имеет `evaluation_mode="FIXED"` и потому не отображается в справочнике норм
вообще (в том числе при наличии legacy-нормы). Первая
настройка выполняется прямо из строки; write-контракт передаёт только
лабораторию, стабильный код исследования (`VSE-F18`–`VSE-F29`) и предметные
значения нормы — тип результата, единицу, версию и источник система
заполняет сама (источник ручной настройки: «Ручная настройка справочника
норм»). Технический редактор нормы (`MethodEditor`) удалён решением DR31.

## Значения enum-вариантов (DR6)

В справочнике норм (эта папка) значения вариантов показателей передаются
и сохраняются как русские надписи (`label`) из общего реестра
`features/examinations/indicators.ts` — конвенция DR6 для страницы
каталога. В форме ВСЭ (`features/examinations`) те же варианты передаются
кодированными значениями (`value`: `MATCH`, `POSITIVE`, `OTHER`, …).
Не смешивать конвенции: реестр один, а представление значения зависит
от страницы.
