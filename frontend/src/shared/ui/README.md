# shared/ui — общие рабочие компоненты

Базовые компоненты рабочих экранов после входа (кнопки, таблицы, диалоги,
поля, иконки, статусные состояния). Здесь же находится низкоуровневый
date-popover primitive.

## DateRangePopover (DR48 §3.4)

Переиспользуемая пара «trigger → popover» для выбора включительного
календарного диапазона («С»/«По», нативные `type=date`). Визуальный паттерн —
как у фильтра даты сверки в «Поступлениях», но классы и поведение принадлежат
этому общему примитиву; страницы не копируют JSX/CSS локально.

- `caption` — постоянная подпись триггера (например «Период отчёта»);
- `applied: { from, to }` — применённый диапазон (ISO `YYYY-MM-DD` или `""`);
- `onApply(range)` / `onReset()` — применение и сброс; до «Применить» запрос
  на сервер никогда не отправляется;
- валидация применения: неполный диапазон — «Укажите дату начала и дату
  окончания периода.», обратный — «Дата начала не может быть позже даты
  окончания.» (`dateRangeError`);
- закрытие по Escape и клику снаружи возвращает фокус на триггер; пока
  поповер открыт, Tab циклится внутри него (минимальный focus-trap);
- триггер показывает «ДД.ММ.ГГГГ — ДД.ММ.ГГГГ» (один день — одну дату) или
  `emptyLabel` («Выберите период»); есть состояние `disabled`;
- на узком экране (≤ 480 px) поля и действия переходят в одну колонку,
  popover не выходит за viewport.

Storybook: `UI/DateRangePopover` (закрытый, открытый, применённый диапазон,
один день, недоступный). Отдельного story для ошибки валидации нет — текст
ошибки показывается только при применении неполного/обратного диапазона.
Используется экраном создания 5-вет
(`features/reports/ReportParameters`).

## Button: вариант dangerSoft (DR52 §9)

Общий `Button` получил семантический вариант `dangerSoft` (CSS-класс `danger-soft`) для спокойной icon-only разрушительной кнопки (например «Удалить ВСЭ» рядом с edit-кнопкой). Токены: `--app-danger-soft-bg: #fbf3f4`, `--app-danger-soft-border: #c97985`, `--app-danger-soft-ink: #9b3440` — те же значения, что у подсветки DEVIATION карточки исследования; hover `#f7e8ea`. Подтверждающие destructive-кнопки в confirm-диалогах продолжают использовать solid `danger`. Stories: `F02/Button` → DangerSoft, DangerSoftIconOnly.

## Прайс-футер: .vse-rec-invoice-footer (DR52 §3.5)

Живой контрол «Ярмарка» формы ВСЭ — контролируемый RHF-checkbox, передаётся в `PricingSection` через prop `waiver` и попадает в общий футер `.vse-rec-invoice-footer` (checkbox слева, итог справа; ≤700px — колонка). Сохранённая карточка (`variant="saved-examination"`) галочку не рендерит.
