# Каталог полей создания ВСЭ и сверки данных

**Редакция v1.3 от 31.10.2026.** В v1.3 добавлены только два необязательных исследования по D-66. Остальной каталог v1.2 сохранён. Продуктовое приложение к PDR-018/019. Состав основан на двух чек-листах владельца с последующими уточнениями в чате. Ценообразование этим каталогом не определяется и не меняется; PDR-011/017 сохраняются.

**Источники:** CK-V — [чек-лист ВСЭ](<sources/чек-лист всэ.docx>); CK-S — [чек-лист сверки данных](<sources/чек-лист сверка данных.docx>). Номера абзацев ниже — структурные номера в исходном DOCX, включая пустые абзацы; они служат трассировке, а не номерам страниц. Исходники сохранены без редактирования. D-58–65 — принятые уточнения. При расхождении с исходным чек-листом действуют уточнения владельца и актуальный PDR.

Под «обязательным» понимается обязательность заполнения/оценки применимого поля при завершении формы. Для черновика сохраняется отдельный режим PDR-009; перечень не превращает неполный черновик в завершённую ВСЭ. «Информационное» — значение для просмотра, без ввода/редактирования. «Обязательная сверка» — нужна отметка врача, а не просто наличие строки из API. Отсутствие результата, «не проводилось» и полученный отрицательный результат не равны.

Трихинеллоскопия описана отдельным показателем; трихинеллёз из старого списка макета не добавлен автоматически в этот словарь.

**Подсказки «Место обнаружения»:** печень; лёгкие; сердце; язык; жевательные мышцы; диафрагма; мышцы туши; кишечник; желудок; лимфатические узлы; туша. Для каждой находки сохраняется её конкретная часть; одинаковый орган у разных туш не объединяет результаты.

**Сохраняемые правила PDR:** массовый ввод — способ заполнения адресных результатов, а не одна первичная платная услуга за партию. Нормы и числовые пределы не заимствуются из демонстрационных данных. Красная подсветка/предупреждение не запрещают выбранный врачом итог, включая «Пригодно», и не меняют результат автоматически. Смена норм не перекрашивает сохранённую оценку.

Для несвиных видов чек-лист не задаёт обязательность/видимость трихинеллоскопии. Пустой дополнительный показатель не равен отрицательному результату. Проверки полноты включённого составного показателя, точность чисел и наличие нескольких находок одной части конкретизируются в будущих ФТ/методике; они не подменены произвольными настройками.

**Несколько значений:** предусмотреть добавление полей, поскольку болезней может быть несколько. Промпт задаёт максимум 10; числовой предел сохранён. Его область — общий для двух групп, для каждой группы или для конкретной части — в промпте однозначно не установлена и не выбрана автором PDR. Это точечное уточнение поведения двух полей, не основание разрабатывать отчёт.

**Скрытие:** каждое из двух необязательных исследований можно скрыть кнопкой × по образцу существующей remove-test. Доступное имя относится к скрываемому исследованию: «Удалить исследование на инфекционные болезни» либо «Удалить исследование на незаразные болезни»; слово «инвазионные» из примера не переносится на другой блок. Самостоятельное правило стирания ранее сохранённых находок при скрытии не вводится.

Промпт относится к мясным и молочным макетам. В продуктовых записях сохранена эта область интерфейсного пожелания; молочный бэкенд этим изменением не включён в мясной MVP. Списки — пользовательский словарь, а не новая медицинская классификация, автоматическое решение о пригодности или правила подсчёта случаев болезни. Новый выбор не заменяет результаты/итоги врача и не меняет самостоятельное исследование «Инвазионные болезни».

### 2.5. Сопроводительные документы

Для предъявленного владельцем документа, отсутствующего в Меркурии, врач отмечает несовпадение и фиксирует фактический документ. Возможность подделки — причина сохранить различие источников, не автоматический диагноз системы. Не вводятся автоматическая проверка подлинности, загрузка сканов, новый статус «Подделка» или безусловный возврат партии. Исходное отсутствие документа не заменяется введённым реквизитом так, будто он был в Меркурии.
