# Участники и продукция в карточке создания ВСЭ

> **История v1.7:** открытый здесь вопрос идентификации частей закрыт в v1.8 D-90/91: исследования, результат и направление относятся ко всей партии. Перечни продукции в этом журнале являются только примером; значения приходят из API Меркурия D-93.

**04.11.2026 · v1.7 · D-81–84.**

Этот журнал фиксирует изменения после встречи с ветеринарными экспертами. Он обновляет продуктовые записи и каталог полей карточки создания ВСЭ. Интерфейсные макеты и функциональные требования в рамках выпуска PDR не изменяются.

## 1. Участники

Прежние поля «Наименование хозяйства / ФИО» и «Адрес владельца» заменяются двумя самостоятельными группами:

- «Сведения об отправителе»: «Название предприятия», «Владелец продукции»;
- «Сведения о получателе»: «Название предприятия», «Владелец продукции».

Это четыре разных реквизита. В реальном эВСД их значения могут различаться, поэтому система не объединяет их и не копирует одно значение в другое. Если в конкретном документе значения совпадают, поля всё равно остаются отдельными. Лаборатория-получатель и собственник продукции не считаются одним субъектом только из-за отображаемого названия.

Источник значений — связанный входящий эВСД и подтверждённый результат приёмки. Решение о возможности локального редактирования этих четырёх реквизитов отдельно не принято; до уточнения карточка следует подтверждённым данным поступления и не меняет внешний документ.

## 2. Классификация продукции

Прежнее поле «Вид мяса» переименовывается в «Продукция». В блоке должны быть четыре поля:

1. «Тип продукции» — первый уровень классификации.
2. «Продукция» — второй уровень.
3. «Вид продукции» — третий уровень и источник смысла количественной единицы.
4. «Название продукции» — номенклатурное название.

По D-93 все четыре значения приходят из связанного эВСД через API Меркурия. Приложенный документ — только пример заполнения, а не исчерпывающий справочник и не источник ручного ввода.

## 3. Состав партии

Поля «Голова» и «Внутренние органы» удаляются. Историческое D-41 больше не определяет актуальную карточку создания ВСЭ.

Вместо таблицы с индивидуальными строками «Маркировка / Часть / Количество» показываются:

- количество фактически принятых единиц;
- одно общее клеймо ветеринарного врача, одинаковое для всех единиц.

Тип части («туша», «полутуша», «четвертина» и подобные значения) не показывается. Индивидуальная маркировка каждой строки не показывается. Возвращённые при частичной приёмке единицы в количество карточки ВСЭ не входят.

Общее клеймо не является уникальным идентификатором части. Поэтому историческое D-16 заменено D-84 для этого блока.

## 4. Исторический вопрос, закрытый в v1.8

В v1.7 модель исследований предполагала результаты по конкретным частям, поэтому отказ от индивидуальных маркировок создавал неопределённость. D-90/91 установили, что исследования и итог относятся ко всей партии; различать части не требуется.

Актуальная система не должна:

- использовать общее клеймо как уникальный ключ;
- генерировать незаметные врачу индивидуальные маркировки;
- создавать отдельные результаты по порядковому номеру, типу части или доле веса.

В функциональных требованиях должна использоваться партийная модель без индивидуальных исследований и смешанного заключения.
