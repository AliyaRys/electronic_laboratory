# Исследования и итог ВСЭ на уровне партии

**04.11.2026 · v1.8 · D-85–93.**

Этот журнал фиксирует изменения карточки создания ВСЭ после встречи с ветеринарными экспертами. Он обновляет продуктовые записи и каталог полей. Интерфейсный код и функциональные требования этим выпуском не изменяются.

## 1. Охват ВСЭ

ВСЭ проводится на всю фактически принятую партию. Для каждого исследования врач вводит одно значение либо один набор значений. Строк и вкладок по отдельным тушам, полутушам, четвертинам и другим единицам нет.

На уровне партии также задаются:

- результат ВСЭ;
- направление по результатам ВСЭ;
- причины направления на обезвреживание, если выбрано сочетание «Условно-пригодно → На обезвреживание».

Исторические смешанные итоги отменены. Система не формирует одновременно пригодный и непригодный результат внутри одной ВСЭ и не выпускает заключение только на часть количества. Идентифицировать отдельные единицы для исследований и итогов не требуется.

## 2. Состав исследований

Добавляется необязательная «Микроскопия». После добавления показывается одно поле «Количество микроорганизмов» для партии. Единица измерения и формат числа должны определяться методикой или справочником; макет их не устанавливает.

«Бактериоскопия» остаётся необязательной, но её значение меняется: врач вводит наименование бактерии. Количество микроорганизмов относится к микроскопии и не дублируется в бактериоскопии.

Добавляется необязательная «Пероксидаза» с двумя значениями:

- «Положительная»;
- «Отрицательная».

Из карточки исключаются:

- ОТС — это осмотр транспорта, а не исследование ВСЭ;
- «Инфекционные болезни» — по ответу ветеринарных экспертов их выявляют на убойном пункте.

«Незаразные болезни» и «Инвазионные болезни» сохраняются как партийные исследования. Для незаразных болезней остаются до 10 значений, собственный текст для варианта «Другое» и восстановление заполненных значений после скрытия блока.

## 3. Результат и направление

Результат имеет один из прежних вариантов: «Пригодно», «Условно-пригодно», «Непригодно». Выбранный результат относится ко всему принятому количеству.

Направление также относится ко всей партии. При результате или направлении, не допускающем свободную реализацию, карточка сохранённой ВСЭ доступна для просмотра, но разрешительное заключение нельзя скачать или распечатать. Исходящий транспортный ВСД врач оформляет в веб-интерфейсе Меркурия.

Для партийного направления «На обезвреживание» сохраняется от одной до пяти обязательных причин из существующего словаря. Блок нельзя скрыть; дополнительные строки можно удалить.

## 4. Расчёт стоимости

Для каждого фактически проведённого исследования:

`Стоимость исследования = тариф исследования × принятое количество из Меркурия`.

Поле «Вид продукции» определяет смысл единицы количества: туши, полутуши, четвертины и иные единицы, переданные Меркурием. Система не определяет единицу по количеству строк интерфейса и не предполагает, что это всегда туши.

Если после частичного гашения принято 3 единицы из 4, расчёт исследования использует принятое количество 3. Возвращённая часть не включается в ВСЭ и её стоимость.

Одно поле результата исследования на партию не означает начисление одного тарифа. Необязательное исследование, которое не было добавлено и проведено, не начисляется.

## 5. Данные продукции

«Тип продукции», «Продукция», «Вид продукции» и «Название продукции» приходят из связанного эВСД через API Меркурия. Приложенный ранее DOCX был примером заполнения полей, а не заданием создать полный локальный справочник.

PDR не перечисляет все возможные значения и не ограничивает ответ API перечнем из примера. Предметный объём MVP по-прежнему определяется PDR-001.

## 6. Границы

Эта редакция не определяет нормативную единицу микроскопии, справочник наименований бактерий, нормы пероксидазы и алгоритм автоматического ветеринарного решения. Отклонение может предупреждать врача, но итог остаётся его выбором.

Не меняются правила приёмки v1.6, роли, внешнее оформление исходящих после ВСЭ и сохранение ранее рассчитанной стоимости при изменении тарифов.
