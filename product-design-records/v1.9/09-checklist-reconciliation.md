# Контроль актуальных полей и макетов

Дата: 04.11.2026. Этот чек-лист сопоставляет решения v1.9 с актуальными мясными макетами. Макеты являются свидетельством интерфейса, но при конфликте действует каталог 08.

## Сверка данных

| Проверка | Требование v1.9 |
| --- | --- |
| Порядок | Документ → участники → транспорт → продукция → документы → прежняя ВСЭ → результаты → стоимость |
| Участники | Для обеих сторон «Название предприятия» и «Владелец продукции»; отдельных адресов нет |
| Транспорт | Вид, ТС, прицеп/«Без прицепа», хранение, состояние отделения, совместный груз |
| Продукция | Четыре уровня, производитель, количество, вес, даты; входящее клеймо только при прежней ВСЭ |
| Решение | Полное/частичное гашение или полный возврат; акт показывается информационной плашкой |
| Повторная ВСЭ | Только при прежней ВСЭ; при выборе «требуется» обязательны основание и № акта |
| Транзакция | Да/нет и условный тип «Внутренняя»/«Внешняя»; данные не запускают операцию |
| Ярмарка | Необязательный признак, итог всех услуг 0 ₽ |

## Карточка ВСЭ

| Проверка | Требование v1.9 |
| --- | --- |
| Участники | Четыре значения из эВСД, только чтение |
| Продукция | Четыре уровня из Меркурия, вес, количество и смысл единицы |
| Клеймо | Одно вводимое клеймо лаборатории; входящее клеймо не подменяется |
| Проба | Обязательный вес, по умолчанию 0,8 кг |
| Охват | Все исследования и итог один раз на партию |
| Трихинеллоскопия | Обязательна для свинины и конины |
| Дополнительные исследования | Есть микроскопия и пероксидаза; бактериоскопия — текст; ОТС/инфекционных болезней нет |
| Итог | Только пригодно/непригодно и зависимое направление |
| Причина | Свободный обязательный текст для утилизации/уничтожения |
| Спецлаборатория | Итог может быть пустым, статус ожидания, заключение заблокировано |

## Известные расхождения макетов, не меняющие PDR

- Если макет позволяет выбрать специалиста вручную, это демонстрационный дефект: должен использоваться активный пользователь.
- Компоненты и stories, где остаются «Условно-пригодно», «На обезвреживание», отдельные части или старые списки причин, являются устаревшими.
- Экраны повторных ветеринарных осмотров являются устаревшими и не входят в MVP.
- Отчётный макет, заполняющий строки формы 5-вет вне 166–172 и 240–242 демонстрационными значениями, не является правилом расчёта.

Эти расхождения следует оформить отдельной задачей синхронизации интерфейса после утверждения PDR; текущая редакция макеты не изменяет.
