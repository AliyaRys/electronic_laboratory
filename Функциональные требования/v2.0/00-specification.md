# 00. Основа спецификации

## Цель и границы

Мясной MVP ведёт входящие транспортные эВСД, сверку, подтверждённую приёмку/возврат через Меркурий, одну действующую местную ВСЭ принятой партии, исследования на партию, цену услуг, заключение, физические пробы и отчётность лабораторий Татарстана. Поддерживаются согласованные мясо и продукты убоя типа «Мясо и мясопродукты»; конкретный перечень идентификаторов — INPUT-02/05.

Не входят молочный и растительный производственный контур, полноценные контуры рыбы и птицы, повторные ветосмотры, склад, продажи, касса, смены сотрудников, автоматизация внутренних перемещений/смены владельца, исходящие ВСД после ВСЭ и для проб, форма 1-вет, история версий ВСЭ, восстановление удалённой ВСЭ, электронная подпись, Max, email-восстановление. Повторная ВСЭ при приёмке с прежней ВСЭ входит. Присутствие экранов и справочников вне MVP не расширяет объём.

## Приоритет и границы решений

Ответы O текущего чата, включая O-12 о тестовом профиле ВУ, source `name` и запрете живого гашения → PDR-001–021 v1.9 → каталог полей 1.9 → D/SC 1.9 → эти ФТ (конкретизация R явно отделена) → непротиворечащие UI-контракты и макеты. Более ранние D и одноимённые PDR не переносятся автоматически. При новом противоречии меняется адресное требование, а не незаметно бизнес-правило в ADR.

## Термины и сущности

| Объект | Обязательный смысл |
| --- | --- |
| Лаборатория | Владелец рабочих записей, тарифов, остатков и отчётов; территория задаёт область доступа |
| Пользователь | Логин, роль, активность, назначения лабораторий/территории и направлений; локальная роль не равна полномочиям Меркурия |
| Входящий эВСД | Устойчивая внешняя идентичность, номер, дата, статус, участники, классификация, количества, прежняя ВСЭ; исходные значения сохраняются отдельно от фактов |
| Партия | Один входящий транспортный эВСД; после приёмки хранит документальное, доставленное, принятое и возвращённое количества/вес без строк отдельных туш |
| Сверка | Отметки сравнения, факты, причины, услуги, решение, повторная ВСЭ, транзакция, ярмарка и состояние внешней операции |
| Местная ВСЭ | Устойчивая идентичность, ручной номер, партия, создатель/время, исследования, проба/отборы, клеймо, итог, стоимость; максимум одна существующая на партию |
| Прежняя ВСЭ | Внешнее основание из эВСД, не локальная карточка и не единица строки 166 нашей лаборатории |
| Физический отбор | Самостоятельный факт пробы: партия, лаборатория, вид продукции, дата, вес, автор; сохраняется при удалении ВСЭ |
| Утилизация проб | Самостоятельное неизменяемое событие списания всего остатка одного вида, дата, вес, внешний номер ВСД, исполнитель |
| Отчёт 5-вет | Неизменяемый сохранённый снимок одной лаборатории за завершённое полугодие, версия правил, классификация и источники |
| Операция Меркурия | Команда, локальная связь, фактическое внешнее состояние и идентификаторы; не подменяется UI-переходом |

Клеймо, название предприятия, порядковый номер строки и ручной номер ВСЭ не являются устойчивым ключом. Повторное использование номера после удаления не восстанавливает прежнюю карточку.

## Состояния и переходы

| Объект | Переход и условие |
| --- | --- |
| Поступление | «Ожидается» → «В работе» после сохранения начатой сверки |
| Приёмка | «В работе» → «Принято» только после подтверждённого полного/частичного гашения с положительным принятым объёмом; полный возврат → «Возвращено» без местной ВСЭ |
| Работа по принятой партии | Собственная ВСЭ необходима → действие создания формы; прежняя ВСЭ достаточна и повторная не нужна → сохранённая сверка и заключение при пригодности |
| ВСЭ | Нет → незавершённая форма (без сохранённой карточки) → завершена либо ожидание результатов; ожидание → завершена после получения ответа и заполнения итога |
| Удаление ВСЭ | Любая существующая карточка → удалена в разрешённый день; партия снова видна «В работе», внешнее подтверждённое гашение сохраняется |
| Внешняя операция | Не отправлена → выполняется → подтверждена / отклонена / исход неизвестен. Из неизвестности — проверка факта, затем решение о безопасном повторе |
| Отчёт | Параметры → предварительный снимок → сохранён; у предварительного нет долговременного черновика; сохранённый не редактируется |

«В работе» — рабочая очередь, а не доказательство непогашенного эВСД. После удаления карточки повторно гасить эВСД нельзя. Название «Принятые» не означает пригодность; непригодная завершённая партия остаётся принятой. Ожидание — сохранённая карточка, незавершённая форма не сохраняется (O-09). Поздняя корректировка итога не сдвигает автоматически дату создания.

## Инварианты

1. Доступ проверяется при каждом чтении и действии по актуальной роли, лаборатории и продукции; авторство не расширяет доступ.
2. ВСЭ охватывает всю принятую партию; результаты, болезни и итог не размножаются на туши. Возвращённое количество исключено.
3. Без подтверждённой приёмки новая ВСЭ и заключение по этой приёмке недоступны; ручная работа в Меркурии требует подтверждения внешнего факта.
4. Все обязательные результаты заполнены для обычного завершения и ожидания; в ожидании разрешено отсутствие только итоговых VSE-F35–37.
5. Отклонение от нормы предупреждает, но не выбирает итог вместо врача.
6. Для завершения только «Пригодно → В реализацию без ограничений» либо «Непригодно → На утилизацию/На уничтожение + свободная причина».
7. Заключение о реализации доступно только по пригодному завершённому основанию. Ни печать, ни сохранение не подтверждают подпись, вручение, оплату или физическое перемещение.
8. Ярмарочная партия сохраняет 0 ₽ по всем услугам; гипотетический платный расчёт не хранится. Она не исключается из исследований и отчётности.
9. Дата создания и срок обычного изменения — серверное Europe/Moscow. После дня создания у ожидающей карточки доступны только итоговые поля; удаление не продлевается.
10. Удаление не отменяет Меркурий, бумажные документы, физические пробы и сохранённый отчёт. Производные текущей ВСЭ пересчитываются без удалённой карточки.
11. Повторное сохранение, открытие и пересоздание ВСЭ не удваивают физический отбор; новый отбор отмечается явно.
12. Стоимость считает принятое количество, 5-вет считает карточки/отдельные исследования, учёт проб — килограммы физического отбора. Эти единицы нельзя смешивать.
13. Изменение справочника не пересчитывает сохранённые результаты и цены. Значения и выводы воспроизводимы без обращения к текущему справочнику.
14. Неизвестное значение не превращается в 0, «Норма», «Не обнаружено» или фиктивный внешний номер.
15. Тестовый ВетИС используется для разрешённого чтения входящих эВСД. Гашение/возврат не вызываются для разработки, тестирования, демонстрации или приёмки; успешные fixture-тесты, доступные credentials и наличие тестового эВСД не разрешают включить `VETIS_WRITE_ENABLED`.
