# 05. Учёт физических проб

Вход — раздел «Отчёты» → «Учёт проб» (O-05). Ветврач видит учёт проб назначенной рабочей области, заведующий — своей лаборатории, аналитик — доступные лаборатории для чтения; администратор не видит. Утилизацию регистрируют только врач/заведующий. Пробы — физические факты, не история версий ВСЭ.

Остаток по лаборатории и виду продукции = сумма ещё не утилизированных фактических отборов. Отборы одного эВСД ссылаются на его сохранённую классификацию. Классификация группировки — «Вид продукции» Меркурия, а не свободное имя/клеймо. Масса партии не уменьшается автоматически на вес пробы (R-06); 5-вет использует принятый вес партии.

Дата отбора остаётся обязательной при сохранении ожидания/завершения. У пробы есть собственный идентификатор, поэтому удаление или перенумерация ВСЭ её не уничтожает.

### FT-SMP-01. Фактический отбор и первый учёт

**Основание:** PDR-008/015; SC-037/071; O-02; R-06.

**Требование:** Вес пробы положителен, по умолчанию 0,8 кг для нового отбора; дата обязательна. При первом сохранении в ожидании/завершении создаётся один физический отбор и увеличивается остаток своего вида. Повторное сохранение того же отбора не увеличивает остаток. Одно значение 0,8 в открытой несохранённой форме не доказывает физический отбор.

**Приёмка:** Сохранение ожидания с 0,8 даёт +0,8 кг; его повторное открытие/завершение не дают ещё +0,8.

### FT-SMP-02. Удаление ВСЭ сохраняет пробу

**Основание:** O-02; PDR-015.

**Требование:** При удалении ВСЭ самостоятельные отборы остаются в текущем остатке, если не утилизированы; утилизированные — в истории утилизации. Сохраняются лаборатория, партия, вид, дата/вес и исполнитель отбора без восстановления удалённых исследований/итога. Ссылка на удалённую ВСЭ не должна открывать её протокол.

**Приёмка:** Удалить завершённую ВСЭ с 0,8 кг: остаток остаётся 0,8; удалить после утилизации: остаток остаётся 0 и событие утилизации доступно.

### FT-SMP-03. Повторное использование и новый отбор

**Основание:** O-04; R-06.

**Требование:** Новая ВСЭ по той же партии по умолчанию использует прежний отбор без повторного начисления. Показываются его дата/вес и состояние утилизации. Для фактического нового отбора требуется явное действие и отдельные дата/положительный вес; новый отбор регистрируется один раз. Утилизированная проба не может предлагаться как физически доступная: при отсутствии доступного отбора нужен новый (R-06).

**Приёмка:** После удаления/пересоздания остаток не удваивается; явный новый отбор 0,5 кг увеличивает его на 0,5.

### FT-SMP-04. Исправление сведений отбора

**Основание:** O-02/03/04; R-06; O-07.

**Требование:** Изменение веса существующего неутилизированного отбора является исправлением того же факта, а не новым отбором: остаток изменяется только на разницу. Доступно только через разрешённую правку карточки. Утилизированный факт не переписывается задним числом; исправления и отмена утилизации исключены O-07. Связанный с ним вес отбора недоступен для изменения, прочие разрешённые правки ВСЭ и её удаление остаются доступными. Дата/вид не меняются незаметно при изменении ВСЭ.

**Приёмка:** Исправление 0,8 на 0,6 до утилизации уменьшает остаток на 0,2; повторное сохранение не вычитает ещё 0,2.

### FT-SMP-05. Просмотр остатков и истории

**Основание:** PDR-015/016; SC-072/079; O-05.

**Требование:** Показываются текущие кг по видам продукции выбранной лаборатории, доступные исходные отборы и история утилизаций: дата, вид, вес, номер внешнего ВСД, исполнитель (R-06). Порог 30/40 кг и автоматическое решение об утилизации отсутствуют. Текущий остаток не обрезается выбранным периодом отчёта; период фильтрует события отдельно.

**Приёмка:** Два вида продукции не смешиваются; изменение периода истории не меняет текущий остаток. Врач не видит форму 5-вет через этот экран.

### FT-SMP-06. Регистрация полной утилизации

**Основание:** PDR-015; SC-073–075; O-01.

**Требование:** Выбирается вид продукции с положительным остатком, дата утилизации и непустой номер исходящего ВСД, реально оформленного в Меркурии. Вес автоматически равен всему актуальному остатку, только чтение. Перед подтверждением показаны вид/вес/дата/номер. Частичное списание и отрицательный/нулевой вес не допускаются. Система исходящий ВСД не создаёт.

**Приёмка:** Для остатка 12,6 кг нельзя ввести 10 кг; подтверждение списывает 12,6 и сохраняет событие, остальные виды не изменяются.

### FT-SMP-07. Конкуренция и неизменяемость списания

**Основание:** O-01/02; PDR-015; R-06.

**Требование:** Если остаток изменился после открытия диалога, подтверждение старого веса отклоняется и требуется показать актуальный остаток. Списание и запись истории выполняются согласованно. Повторное действие не создаёт второй документ/списание. Сохранённая утилизация не редактируется/удаляется обычной операцией, исправления и отмена исключены O-07. Номер введённого внешнего ВСД не выдаётся за автоматически проверенный API-факт.

**Приёмка:** Два врача одновременно не списывают один остаток дважды; новый отбор после списания создаёт новый положительный остаток. Утилизация не увеличивает строки 240–242 5-вет.
