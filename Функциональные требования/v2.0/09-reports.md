# 09. Отчёты

Раздел объединяет учёт проб, операционные показатели и регламентированную форму 5-вет. По O-05 врач видит только учёт проб; заведующий — все отчёты своей лаборатории. Аналитик читает доступные данные и формирует отчёты по одной выбранной лаборатории Татарстана, не регистрируя лабораторные физические операции. Администратор не видит раздел. Старый путь admin_makets не является правом администратора.

## Алгоритм формы 5-вет

Отбор: лаборатория совпадает, местная ВСЭ завершена, не удалена, первое время завершения попадает в полугодие Europe/Moscow. I полугодие: [1 января 00:00; 1 июля 00:00), II: [1 июля 00:00; 1 января следующего года 00:00). Ярмарочные и внутренние партии входят; несохранённые формы, ожидание и прежние внешние ВСЭ без местной не входят. Исправление завершённой карточки не меняет период первого завершения (R-04).

| Строка | Вклад одной отобранной ВСЭ |
| --- | --- |
| 166 | 1, независимо от количества туш/исследований |
| 167 | +1 за выполненную бактериоскопию и отдельно +1 за микроскопию |
| 168 | +1 за выполненную трихинеллоскопию |
| 169 | По +1 за выполненные pH, пероксидазу, реакцию с сернокислой медью |
| 170 | +1 за дозометрическое исследование с двумя показателями, а не +2 |
| 171 | По +1 за пробу варки, люминесцентный анализ, температуру в толще мышц |
| 172 | +1 за отправку в аккредитованную лабораторию после ответа и завершения ВСЭ |
| 240 | Принятый вес партии / 1000, только направление «На уничтожение» |
| 241 | Часть 240, классифицированная как мясо |
| 242 | Часть 240, классифицированная как субпродукты |

Органолептика, идентификация, перечни болезней и свободные причины не увеличивают строки 167–172 сами по себе. Находка трихинеллёза не дублирует выполненную трихинеллоскопию. Строка 166 не обязана равняться сумме 167–171. Утилизация проб не относится к 240–242.

Колонки формы: КРС/яки/буйволы; свиньи; овцы/козы; кролики/нутрии; птица — куры/другие; рыба; другие животные. Наличие колонки не расширяет мясной MVP на рыбу/птицу. Конкретные идентификаторы видов, животное и мясо/субпродукты задаёт INPUT-05. Автоматически считаются только 166–172/240–242; прочие строки полного образца не рассчитываются по догадкам и обозначаются как нерассчитанные до утверждения формы (INPUT-04).

### FT-RPT-01. Доступ и состав раздела

**Основание:** PDR-003/016/017; O-05; SC-009/076.

**Требование:** Врач открывает раздел «Отчёты» только с учётом проб. Заведующий видит учёт проб, операционные показатели и 5-вет своей лаборатории. Аналитик формирует отчёты и читает доступные лаборатории. Все списки/снимки/выгрузки проверяют доступ; администратору запрещено даже прямым запросом.

**Приёмка:** Врач не открывает 5-вет по известному URL, администратор — отчётный снимок. Заведующий не формирует по чужой лаборатории.

### FT-RPT-02. Операционные показатели

**Основание:** PDR-004/016; SC-013/014/076–079; R-09.

**Требование:** За выбранный период и лабораторию показываются обработанные партии, выполненные идентификации продукции и осмотры транспорта. Обработанная партия — одна подтверждённо завершённая сверка, кроме отмеченных внутренних транзакций (R-09). Каждая действительно выполненная и сохранённая услуга даёт одну единицу своего показателя независимо от тарифного множителя. Полный возврат без услуги её не добавляет. Для показателей используется время завершения соответствующего факта, не дата создания ВСЭ (R-09). Остатки проб показываются как текущие, история — за период.

**Приёмка:** Одна сверка с двумя оказанными услугами и внутренней транзакцией: 0 обработанных, +1 идентификация, +1 транспорт. Отсутствие оказанной услуги даёт 0 по ней.

### FT-RPT-03. Создание формы 5-вет

**Основание:** PDR-017; SC-080; макеты отчётов; R-09.

**Требование:** Выбираются единственный тип «5-вет, раздел III», одна доступная лаборатория и завершённое полугодие. Нельзя выбрать текущее незавершённое. По сочетанию тип/лаборатория/год/полугодие существует максимум один сохранённый отчёт. При отсутствии отобранных ВСЭ формирование блокируется с объяснением (R-09). Нет ручного редактирования расчётных ячеек или долговременного черновика.

**Приёмка:** На 05.11.2026 допустимо I полугодие 2026, II недоступно. Конкурирующее сохранение дубля отклонено.

### FT-RPT-04. Проверяемый расчёт и классификация

**Основание:** PDR-017; SC-081–088.

**Требование:** Матрица считается по таблице выше и сохранённой классификации. Неподдержанное/неоднозначное соответствие не распределяется по похожему названию; формирование требует исправить конфигурацию и не выдаёт частичный успешный отчёт. Вес суммируется до итогового отображаемого округления, кг переводятся в тонны без округления отдельных партий; точность официальной формы — INPUT-04.

**Приёмка:** Одна ВСЭ с бактериоскопией, микроскопией, pH, пероксидазой и температурой даёт 166:+1, 167:+2, 169:+2, 171:+1. Уничтоженные 250 кг мяса дают 240:+0,25 т, 241:+0,25 т.

### FT-RPT-05. Предварительный снимок и семь кодов

**Основание:** PDR-017; макеты отчётов; R-09.

**Требование:** «Сформировать» фиксирует предварительный набор источников, матрицу, лабораторию/адрес и период. Перед сохранением вручную вводятся семь непустых кодов: ОКУД, ОКПО, ОКВЭД, ОКТМО, ОКОГУ, ОКОПФ, ОКФС. По краям обрезаются пробелы; маски/автопоиск не придумываются, из прошлых отчётов коды не подставляются. «Изменить параметры» очищает предварительный снимок и коды после предупреждения.

**Приёмка:** Нельзя сохранить с одним пустым кодом; введённые 001 сохраняют ведущие нули; ошибка сети не теряет снимок/коды.

### FT-RPT-06. Неизменяемый сохранённый отчёт

**Основание:** PDR-014/017; SC-070.

**Требование:** «Сохранить» сохраняет именно показанный снимок: лабораторию/адрес, период, время формирования, автора, коды, матрицу, число и идентичности источников, версию правил/соответствий и точность (R-09). Поздние исправления/удаления ВСЭ и изменения справочников его не пересчитывают. После успеха открывается просмотр без редактирования.

**Приёмка:** Удалить одну исходную ВСЭ после формирования: сохранённая матрица и выгрузка прежние; новый предварительный расчёт без неё.

### FT-RPT-07. Список и просмотр отчётов

**Основание:** Макеты отчётов; R-03/09.

**Требование:** Список: полугодие, лаборатория, число ВСЭ, время формирования, действия. Поиск по лаборатории, год/полугодие, сортировка, 20 строк и возврат с контекстом. В действиях просмотр, Excel, PDF, печать, удаление. Меню не активирует переход строки; строка доступна как ссылка клавиатурой. Просмотр показывает служебную сводку и официальную форму.

**Приёмка:** На 25 отчётах работают вторая страница и возврат; удалённый в другой вкладке отчёт показывает «Не найден».

### FT-RPT-08. Экспорт и печать отчёта

**Основание:** Макеты отчётов; PDR-017; R-09; INPUT-04.

**Требование:** Excel/PDF/печать используют сохранённый снимок, не пересчитывают текущие карточки. Экспорт содержит организационную шапку, период, семь кодов и официальную матрицу без интерфейсной сводки/кнопок. Числа Excel остаются числами, коды текстом с ведущими нулями. Заголовки повторяются при печати, колонки не обрезаются. Имя: 5-вет_раздел-III_<лаборатория>_<год>_<полугодие> с безопасными символами.

**Приёмка:** Сопоставить матрицу экрана, xlsx, PDF и печати после изменения источника: все равны сохранённому снимку.

### FT-RPT-09. Удаление сохранённого отчёта

**Основание:** Макеты отчётов; R-09.

**Требование:** Заведующий/аналитик в своей отчётной области удаляют снимок после подтверждения лаборатории/периода и отсутствия восстановления. Карточки и физические пробы не меняются, скачанные файлы не отзываются. Период снова доступен; повторно сформированный отчёт использует текущие источники и правила.

**Приёмка:** После удаления последней строки страницы корректируются счётчик/страница; новый отчёт по периоду не наследует старую матрицу.
