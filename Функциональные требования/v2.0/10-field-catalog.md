Бронхит; пневмония; бронхопневмония; плеврит; плевропневмония; перикардит; миокардит; эндокардит; цирроз печени; капиллярная эктазия печени; жировая дистрофия печени; нефрит; нефроз; эндометрит; параметрит; мастит; тимпания; гастрит; энтерит; гастроэнтерит; беломышечная болезнь; истощение; новообразование; другое незаразное заболевание.

### 1.6. Доступность действий карточки

- «Сохранить в ожидании» доступно, если VSE-F33 выбран и заполнены остальные обязательные данные, кроме VSE-F35–37.
- «Сохранить/завершить ВСЭ» требует VSE-F35–37 по матрице.
- Заключение доступно только для завершённого результата «Пригодно».
- В день создания ожидающей карточки ветврач или заведующий может исправлять все редактируемые поля; после дня создания — только VSE-F35–37, независимо от даты получения ответа (O-03).
- Обычное редактирование и удаление доступны ветврачу/заведующему до конца календарного дня создания; аналитик и администратор не могут изменять карточку.

### 2.9. Вес и состав при приёмке

При положительном документальном весе процент отклонения равен `(фактический вес − вес эВСД) / вес эВСД × 100%`. Диапазон от −5% до +5% включительно не требует акта только по основанию веса. Большее отклонение при полном/частичном принятии требует акта.

Недостача не является возвращаемым отсутствующим товаром. При частичном гашении принятый плюс возвращаемый фактически доставленный объём равен доставленному. В карточку ВСЭ передаётся только принятый состав.

### 2.10. Доступность решений

- Блокирующее расхождение с отправителем, владельцами/получателем, типом/продукцией/видом, производителем, датой выработки, видом транспорта или способом хранения запрещает полное и частичное принятие, если API не допускает исправление.
- Допустимое с актом расхождение названия продукции, количества, веса, срока годности, номера ТС/прицепа или транспортного документа разрешает полное/частичное принятие после заполнения факта и причины.
- Состояние грузового отделения и совместная перевозка не выбирают решение автоматически; решение принимает врач в пределах доступных API-вариантов.
- Частичное гашение требует реального разделения партии и причины возврата.
- Полный возврат требует причины возврата и не ведёт к карточке ВСЭ.
- Статус эВСД, не допускающий операцию, блокирует завершение.

## 3. Отчётные производные

Из карточек и сверок рассчитываются, но не вводятся отдельными полями:

- текущий накопленный вес проб по лаборатории и виду продукции;
- количество обработанных внешних партий;
- количество идентификаций продукции и осмотров транспорта;
- строки 166–172 и 240–242 формы 5-вет по правилам PDR-017.

Операция обнуления проб отдельно вводит вид продукции, дату и номер исходящего ВСД; вес подставляется из всего актуального остатка и недоступен для ручного изменения (O-01). Событие сохраняется в истории и не отменяется/не исправляется в MVP (O-07).

### Список пробы варки

Из актуального макета: «Бульон прозрачный, аромат специфический»; «Бульон мутный»; «Бульон с хлопьями»; «Бульон с осадком»; «Нехарактерный / неприятный запах»; «Иное (указать)» с обязательным текстом. Клиническая оценка каждого значения — INPUT-02, не по цвету демо. Органолептика/идентификация/люминесценция — «Соответствует / Не соответствует»; трихинеллоскопия — типизированный результат по подтверждённой методике, без текстовой подстановки пустого в отрицательный.

### Общие проверки дат

Дата создания/фиксации/завершения автоматическая; дата отбора/утилизации пользовательская. Дата физического события не может быть будущей на момент фиксации (R-06); при использовании старой пробы дата не заменяется датой новой ВСЭ. Утилизация не может предшествовать включённым отборам. Неприменимая классификация блокирует только зависящий расчёт, не изменяет значение из Меркурия.
