# 13. Подтверждённые операции удаления

O-06 сохраняет три функции прежней версии с ограничением новой ролевой моделью. Наличие удаления не возвращает бессрочное удаление ВСЭ или отдельные пять универсальных флажков.

### FT-ADM-01. Назначение всех четырёх ролей

**Основание:** O-08; PDR-003/018.

**Требование:** Администратор может назначать любую из четырёх ролей только при наличии предоставленных ему полномочий на эту роль и её область. Право администрировать город само не позволяет назначить республиканского аналитика. Полномочия делегирования проверяются при сохранении, не расширяются самим администратором; их первичная выдача — OPS-01. Роль аналитика сохраняет область всех лабораторий Татарстана, а не превращается в городскую роль.

**Приёмка:** Городской администратор без права республиканского назначения не создаёт аналитика подменой запроса. Разрешённое назначение не даёт администратору права читать созданные рабочие записи.

### FT-ADM-02. Удаление пользователя

**Основание:** O-06; прежний FT-ACC-13; R-02.

**Требование:** Администратор удаляет доступного пользователя после проверки связей и подтверждения. Пользователь с рабочими/историческими связями не удаляется: вместо этого доступна блокировка; авторство и события сохраняются. Нельзя удалить текущую собственную запись или последнего уполномоченного администратора области (R-02). Политика сохраняется для четырёх ролей, с проверкой полномочий управления целевой записью.

**Приёмка:** Связанная с ВСЭ запись не исчезает и не обнуляет специалиста; несвязанная удаляется и больше не входит.

### FT-ADM-03. Удаление ожидаемого поступления

**Основание:** O-06; прежний FT-ARR-19; R-03.

**Требование:** Врач/заведующий удаляет только доступную ожидаемую местную запись без начатой сверки/ВСЭ/внешнего исполнения, после подтверждения. Внешний эВСД не аннулируется. Повторное получение неизменённого документа не возвращает скрытую запись; изменённый внешний документ может появиться вновь (R-03). Это не удаление принятой партии.

**Приёмка:** Повторное обновление не воскрешает неизменённую удалённую ожидаемую строку; принятая партия не удаляется этим действием.
