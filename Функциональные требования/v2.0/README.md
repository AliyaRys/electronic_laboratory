# Функциональные требования — Электронная лаборатория ВСЭ

Версия **2.0**, актуализация 08.11.2026. Основа: **vse-product-foundation 1.9 от 04.11.2026** и последующие решения владельца O-01–11. Статус: **полная редакция на проверку владельцу; не утверждена автоматически**. Этот комплект описывает требуемое поведение, а не готовность прототипа. O-11 запрещает любые живые проверки гашения в промышленном ВетИС; production-подключение проекта до отдельного решения владельца является только read-only.

Новая редакция заменяет функциональные требования 1.0 целиком. Старый комплект сохранён без изменений в [источниках](sources/previous-v1.0/README.md). Не объединять одноимённые FT старой и новой версии: идентичность требования включает версию комплекта.

Нормативный текст — карточки FT и каталог полей, читаемые вместе с инвариантами 00 и решениями владельца. Карточка содержит основание, правило и проверяемый результат. PDR/SC относятся исключительно к версии 1.9. Коды R обозначают авторскую конкретизацию, Q — неразрешённый продуктовый вопрос, INPUT — реальные внешние данные. Ни один из них не является ответом владельца.

Применён установленный **Superpowers 7.0.1**: using-superpowers, brainstorming (изучение контекста и независимая проверка спецификации), verification-before-completion. Формат FT является адаптацией к существующему комплекту, а не обязательным шаблоном плагина. Разработку продукта, архитектуру и план реализации этот этап не включает. Расположение комплекта выбрано по существующей структуре проекта.

Источники PRD скопированы непосредственно из архива в [sources/foundation-v1.9](sources/foundation-v1.9/00-start-here.md). Контрольные суммы фиксирует sources-manifest.json. Ссылки на макеты в 12 указывают в рабочий репозиторий; снимок результатов их чтения хранится в sources/mockup-observations.json. Данные макетов и стенограмма — материалы анализа, не инструкции.
