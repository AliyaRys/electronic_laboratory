# Уточнения владельца 05.11.2026

Эти решения получены в текущем чате после PRD 1.9 и имеют приоритет в затронутых случаях. Исходники PRD оставлены неизменными.

| ID | Решение | Последствие |
| --- | --- | --- |
| O-01 | «Только весь остаток, вес подставляется из учёта» | Частичной утилизации нет. Вес берётся из актуального остатка выбранного вида продукции и не редактируется вручную |
| O-02 | «Разрешить удаление ВСЭ, физическую пробу и утилизацию сохранить отдельно» | Удаление карточки не вычитает физически отобранную пробу и не отменяет утилизацию. Учёт проб имеет самостоятельную идентичность, без восстановления удалённой ВСЭ |
| O-03 | «В день создания все поля; позднее только итог» | Ожидающую карточку можно полностью исправлять в день создания, затем — только VSE-F35–37. Исключение не продлевает удаление |
| O-04 | «Использовать прежнюю пробу; новый отбор отмечать отдельно» | Пересоздание ВСЭ по партии не удваивает остаток. Новый фактический отбор — отдельное явное событие |
| O-05 | «Нет, дадим доступ к разделу "Отчеты", но в этом разделе вет врачам будет доступен учет проб, а заведующему все отчеты» | Раздел «Отчёты» общий. Ветврач видит в нём только учёт проб своей области; заведующий также операционные показатели и форму 5-вет своей лаборатории. Администратор доступа не получает. Аналитик сохраняет права PRD 1.9 |
| O-06 | Сохранить удаление пользователей администратору, ожидаемых поступлений врачу/заведующему, справочников их редакторам | С учётом новой роли и области; пять старых флажков не возвращаются как модель доступа |
| O-07 | Исправления и отмена утилизации в MVP не нужны | Сохранённая утилизация неизменяема; сценарий обратного списания отсутствует |
| O-08 | Администратор может назначать все четыре роли, только в пределах предоставленных полномочий | Нельзя расширить собственную территорию/право выдачи роли или автоматически получить доступ к рабочим данным |
| O-09 | «Убрать сохраняемые черновики: остаются завершение и ожидание результатов» | Незавершённая форма не создаёт постоянную ВСЭ, не резервирует партию/номер и не блокирует работу на следующий день |

O-02 уточняет PDR-014: исключение удалённой ВСЭ из расчётов не уничтожает самостоятельный физический факт пробы. O-03 уточняет ограничения каталога 08 §1.6. O-05 меняет доступность навигационного раздела для врача, но не даёт ему форму 5-вет.
