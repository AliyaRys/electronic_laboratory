# 03. Собственная ветеринарно-санитарная экспертиза

## 1. Назначение и форма

Собственная ВСЭ регистрирует работу лаборатории по всему принятому составу одного поступления. База: PDR-004/008/009/014, D-16/19/21/27/32–36/39/41. Поля исходных мясных форм S-03/04 — источник состава, но их демонстрационные проверки не являются готовой методикой.

### Словарь полей ВСЭ

**Детализация R-01/07/11.** «Обязательно» ниже означает обязательность завершения; черновик сохраняется по FT-VSE-07.

| Поле | Источник и проверка |
|---|---|
| Поступление / эВСД | Обязательная связь с принятым положительным составом; исходные номер/дата доступны для чтения, внешний идентификатор не меняется свободным вводом |
| Номер решения о назначении ВСЭ / номер ВСЭ | Один ручной номер на запись; положительная последовательность 1–20 цифр; крайние пробелы удаляются, ведущие нули убираются до проверки уникальности и отображения. Нет массива номеров «на каждую тушу» |
| Дата и время обращения | Обязательно, фактическое время МСК; не позже текущего времени; не подставляется старое демонстрационное значение |
| Владелец, адрес | Обязательно, достоверные данные приёмки; нет подмены на лабораторию. Неизвестный адрес можно уточнить фактическим текстом; отдельный адресный сервис MVP не требует |
| Вид мяса и наименование | Обязательно: говядина / баранина / свинина / мясо прочих животных. Для прочих указан фактический вид животного, чтобы выбрать применимую методику |
| Состав | Все принятые маркированные части; тип, количество, масса и единица; общий вес как сумма при полной детализации; нет новых лабораторных маркировок |
| Голова, внутренние органы | Два обязательных общих значения «Есть/Нет» по партии; исходно не выбраны. Не отдельные флажки по тушам |
| Исследования | Типизированные значения и применённые нормы по каждой исследованной части; обязательность определяется проверенной методической таблицей |
| Дата отбора материала | Обязательна при методике, предусматривающей отбор; реальная дата, не позже времени завершения; методическая применимость — INPUT-02 |
| Внешняя запись Меркурия по результатам | Если реально существует — идентификатор и происхождение. Необязательна для местного завершения при неподтверждённой внешней операции; не цифры по умолчанию |
| Инвазионные находки | При добавлении: болезнь, место обнаружения и маркировка затронутой части; для «другое» — название. Перечень кандидатов из макета требует INPUT-02 |
| Итог и направление | Для каждой принятой части обязательный итог и применимое направление; раздел 04 |
| Специалист Госветслужбы | Текущий пользователь при создании; нередактируемое поле. Сохраняется при открытии, исправлении и печати коллегой |
| Стоимость | Расшифровка услуг и применённых тарифов; раздел 06; не свободный ввод общей суммы |

## 2. Кандидатный состав исследований для INPUT-02

Ни таблица, ни числа HTML не утверждают клиническую норму. До продуктивного завершения для каждого поддержанного вида должна быть проверенная строка методики: **вид/состояние продукции → показатель → метод → тип результата → единица/точность → обязательность/условие → правило оценки с границами → источник/редакция → проверяющий**. Если необходимой конфигурации нет, завершение соответствующей ВСЭ недоступно с перечнем недостающего; черновик разрешён.

| Исследование из мясных форм | Представление значения | Что требуется проверить |
|---|---|---|
| Органолептика | «Соответствует/Не соответствует» по части | Метод, обязательность и достаточность словаря |
| Идентификация | «Соответствует/Не соответствует» по части | Различие с услугой сверки, обязательность, исключение двойного начисления одной услуги |
| Трихинеллоскопия | «Обнаружено/Не обнаружено» по части | обязательно для вида продукции "свинина" |
| Температура в толще мышц | Число, °C по части | Состояние охлаждённое/замороженное, допустимость отрицательных значений, границы и точность |
| Люминесцентный анализ | Качественный результат по части | Противоречие раннего списка обязательных и дополнительных карточек; обязательность решает методика |
| Бактериоскопия | Число и методическая единица по части | Единица, физические ограничения, способ оценки |
| pH | Число по части | Метод, точность и границы; не переносить демонстрационный диапазон |
| Проба варки | Проверенный вариант; «Иное» с текстом | Полный словарь, какой вариант отклонение, применимость |
| Реакция с сернокислой медью | «Положительная/Отрицательная» | Метод и значение результата для оценки |
| ОТС | Качественное значение | Расшифровка термина, метод, применимость и словарь |
| Дозиметрическое исследование | Мощность дозы от части и гамма-фон, мкЗв/ч | Метод сравнения пары, единицы, точность и обязательность обоих полей |
| Инвазионные болезни | Список находок «часть — болезнь — орган/ткань» | Набор, обязательность, связь результатов, единица тарификации |

Общие результаты для нескольких частей можно вводить массовым действием, но результат и начисление остаются адресными. Отдельный журнал проб, генерация этикеток и самостоятельные состояния образцов не появляются.

## 3. Требования

### FT-VSE-01. Единственная местная ВСЭ принятой партии

**Происхождение:** база PDR-004/007, D-18/39.

**Правило:** создание доступно для принятой партии с положительным составом, которой нужна собственная экспертиза и у которой нет существующей местной ВСЭ. При наличии черновика/завершённой записи открывается она. Все принятые части входят в одну запись; разные итоги её не дробят. При применимой внешней ВСЭ создание дублирующей местной недоступно.

**Приёмка:** параллельные действия двух врачей по одной партии не сохраняют две местные ВСЭ; три разных итога туш остаются внутри одной записи.

### FT-VSE-02. Ручной номер и специалист

**Происхождение:** база PDR-009, D-33–36; детализация R-01.

**Правило:** номер вводит врач, автоматической подстановки нет. Уникальность среди всех существующих местных ВСЭ лаборатории, включая черновики с номером, без годового сброса. У собственной записи неизменённый номер допустим. Параллельное сохранение дубля не допускается. После удаления номер свободен. Специалист заполняется текущим врачом однократно при создании; нет ручного выбора другого или смены при исправлении коллегой.

**Приёмка:** в 2027 нельзя сохранить номер существующей ВСЭ 2026 года; `001` и `1` по предложенному R-01 совпадают; новая запись после удаления не наследует старых данных/осмотров.

### FT-VSE-03. Адресность результатов и изменение состава

**Происхождение:** база PDR-004/008; D-16/39/41; детализация R-07/11.

**Правило:** результаты и итог связаны с конкретной принятой частью по устойчивой связи, а не порядковому номеру строки. Перестановка отображения не переносит результаты. Изменение массы/состава приёмки после начала ВСЭ не перекидывает результаты на другие маркировки; завершение требует согласованного актуального состава. Удаление исследованной части из принятого состава требует явного исправления затронутых данных, с проверкой заключения и внешних документов по FT-DOC-11.

**Приёмка:** сортировка частей не меняет, у какой туши выявлено отклонение; вернувшаяся часть не остаётся разрешённой в документе.

### FT-VSE-04. Типы и полнота результатов

**Происхождение:** база PDR-008/009; D-19; INPUT-02; детализация R-11.

**Правило:** форма отражает применимые обязательные/дополнительные исследования. Пусто, «не проводилось» и полученный отрицательный/положительный результат — разные значения. Обязательное применимое исследование не скрывается удалением карточки. Дополнительное выполняется только по выбранным частям; для каждой выбранной части нужен полный типизированный результат, в том числе оба показателя дозиметрии, если так задан метод. Неисследованные части не получают значения автоматически.

**Приёмка:** при отсутствии обязательного результата завершение запрещено с указанием исследования и маркировки; реальное «не обнаружено» сохраняется как результат, а не как пустое поле; неактивное дополнительное не начисляется.

### FT-VSE-05. Массовый ввод

**Происхождение:** база PDR-008/011, D-27; S-03; детализация R-11.

**Правило:** врач может применить один результат ко всем либо явно выбранным исследуемым частям. Перед действием понятен охват; уже отличающиеся заполненные значения не перезаписываются молча, требуется явное подтверждение замены. После действия можно исправить отдельную часть. Массовый ввод не означает один факт исследования за всю партию и не снижает первичный множитель.

**Приёмка:** результат четырём тушам тарифицируется четырьмя услугами; последующее исправление третьей не меняет остальные.

### FT-VSE-06. Оценка нормы и решение врача

**Происхождение:** база PDR-008/011; D-19/32.

**Правило:** оценка «Норма/Отклонение» рассчитывается по применимой проверенной норме и показана текстом, не только цветом. При отклонении есть заметное предупреждение с показателем, маркировкой, значением и применённой нормой. Можно завершить с выбранным врачом итогом, в том числе «Пригодно». Не меняются исходное значение и итог; обязательная причина, согласующий и автоматический запрет из отклонения не вводятся. При неизвестной норме оценка «Не определена», не зелёная.

**Приёмка:** выход за норму предупреждает, заполненная запись с итогом «Пригодно» завершается; отсутствие обязательного результата по FT-VSE-04 продолжает блокировать завершение.

### FT-VSE-07. Черновик

**Происхождение:** основа PDR-009, S-03; детализация R-01/11.

**Правило:** «Сохранить как черновик» сохраняет неполные местные данные без заключения и статуса завершения. Минимум — связь с принятой партией, текущий специалист и действующий доступ. Пустой номер допустим только в черновике; если введён — формат и уникальность проверяются уже при сохранении. Некорректные введённые числа/даты не сохраняются как валидные. Нет скрытой автонумерации и обещания автосохранения.

**Приёмка:** черновик без результатов открывается после входа и не даёт заключение; ошибочное число не превращается в нуль; черновик с занятым номером отклонён.

### FT-VSE-08. Завершение ВСЭ

**Происхождение:** база PDR-006/008/009/010/011; D-19/24/28/29; детализация R-11.

**Правило:** проверяются обязательные реквизиты таблицы, согласованный принятый состав, уникальный номер, методика, обязательные результаты, итоги/направления всех частей и корректность расчёта услуг. Успех сохраняет целиком результаты, оценки с основаниями, итоги и расчёт и делает запись завершённой. Внешнее гашение, транспорт для позднего вывоза и отклонение результата сами по себе не блокируют. При недостающем тарифе нельзя выдавать сумму 0 как полный расчёт; применяется FT-CAL-10.

**Приёмка:** неполная запись остаётся черновиком; при успехе журнал и карточка показывают одну завершённую ВСЭ с теми же данными, печать получает только пригодную часть.

### FT-VSE-09. Просмотр и журнал

**Происхождение:** база PDR-003/009/010/012; S-04; детализация R-06.

**Правило:** карточка показывает реквизиты, весь состав, исследования и оценки по маркировкам, общий признак смешанного итога, индивидуальные итоги/направления, стоимость и специалиста. Журнал местных ВСЭ содержит завершённые записи; черновики доступны в «В работе». Внешняя ВСЭ не выдаётся за местную строку. Колонки журнала: номер, дата/время обращения, владелец, эВСД, продукция/количество/масса, итог, специалист, сумма; просмотр полного результата по ссылке.

**Приёмка:** карточка открывается по идентичности выбранной строки; чужое демонстрационное хозяйство не подставляется; неоднородная партия не подписана просто «Пригодно».

### FT-VSE-10. Исправление завершённой записи

**Происхождение:** база PDR-009/012, D-15/21; детализация R-05/12.

**Правило:** врач с основным правом исправляет доступную запись, включая чужую завершённую с выданной бумагой. Сохранение перезаписывает актуальные данные без версии, причины и согласования. Для завершённой записи применяются полные проверки завершения; ошибка не стирает прежние данные. При изменении исследований/услуг действуют правила сохранения применённых норм/цен раздела 06. Простое изменение текста не переоценивает все исследования.

**Приёмка:** после правки коллегой повторная печать использует текущие данные; в продукте нет кнопки старой версии; неизменённые расчёт и специалист не заменены автоматически.

### FT-VSE-11. Стабильность сохранённой оценки

**Происхождение:** база PDR-008/011, D-32; детализация R-12.

**Правило:** каждая оценка сохраняет результат, применённую единицу/критерий/границы и правило сравнения. Просмотр/печать используют их даже после смены/удаления текущей нормы. При намеренном исправлении значения существующего исследования оценка выполняется по закреплённому в записи критерию; новый показатель использует текущую применимую норму. Это конкретизация R-12; отдельное действие массовой переоценки не вводится.

**Приёмка:** норма изменилась — сохранённая красная подсветка прежняя; исправлено значение — оценка меняется согласно явно показанному старому критерию, не скрыто новой норме.

### FT-VSE-12. Удаление ВСЭ на любой стадии

**Происхождение:** база PDR-003/009/012–014; D-10–14/22/35; детализация R-13.

**Правило:** отдельное право удаления допускает удаление черновика или завершённой доступной ВСЭ, в том числе чужой. Подтверждение перечисляет последствия: сама ВСЭ, заключение и все связанные осмотры исчезнут, восстановление в продукте отсутствует; бумага и внешние документы сохраняются вне этой операции. Удаление выполняется целиком, освобождает номер. Нет обязательной причины, архива и журнала удалённых ВСЭ. Принятое поступление сохраняется; по R-13 после удаления доступен новый цикл создания своей ВСЭ по той же партии без автоматического переноса прежних данных.

**Приёмка:** после удаления с тремя осмотрами старые ссылки не открывают ни одну из четырёх записей/заключение; номер можно использовать; поступление остаётся, внешний ВСД не аннулирован.
