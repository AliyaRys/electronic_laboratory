# 05. Повторные ветеринарные осмотры

## 1. Назначение и поля

База: PDR-004/007/011–014; D-09/20/22/25/42–44/46. Осмотр оформляет врач по обращению владельца принятой партии; система хранит событие наблюдения, а не вычисляет склад или актуальный запрет реализации.

**Детализация R-15** по S-12:

| Поле | Правило |
|---|---|
| Принятое поступление | Обязательная неизменяемая связь; эВСД, владелец, адрес, продукция и исходный принятый состав доступны для чтения |
| Основание экспертизы | Существующая завершённая местная ВСЭ либо применимая внешняя, не фиктивная новая местная запись |
| Дата/время осмотра | Фактические, МСК, обязательны; не раньше местной приёмки и не в будущем |
| Специалист | Текущий врач при создании, нередактируемый; сохраняется при правке коллегой |
| Фактический остаток | Ввод врача для этого осмотра: масса/единица и количество частей, маркировки исследуемых оставшихся частей при наличии; не вычисляется из продаж |
| Условия хранения | Фактически наблюдаемые условия текстом либо проверенный вариант, обязательны; варианты камеры из макета не исчерпывают реальность |
| Выполненные исследования | Выбранные применимые показатели, результаты по исследованным частям/охвату и единицы; для включённого показателя результат обязателен |
| Результат осмотра | Обязательное решение врача; кандидатные подписи из S-12: «Реализацию продолжить», «Реализацию приостановить», «Направить на дополнительную экспертизу», «Утилизировать»; предметное содержание проверяется INPUT-02 |
| Комментарий | Необязательный фактический текст до 4000 символов, без заранее выбранного положительного описания |
| Стоимость | Один тариф каждого выполненного показателя на партию за осмотр; применённые цены и сумма сохраняются |

Наблюдаемый остаток не ограничивается автоматически последним наблюдением; увеличение вызывает предупреждение и предложение проверить числа, а не создаёт новую поставку. Остаток больше исходно принятого — предупреждение R-15, без автоматической корректировки, поскольку наблюдение и исходные сведения могут требовать исправления. Исследуемые маркировки при этом должны принадлежать принятой партии; чужие части не присоединяются молча.

## 2. Требования

### FT-REP-01. Инициатива и точка входа

**Происхождение:** база PDR-013; D-43/44.

**Правило:** из карточки принятой партии/связанной завершённой ВСЭ врач с основным правом открывает осмотр при обращении владельца. Для всех партий автоматически осмотр не создаётся, срок обязательного переосмотра не назначается. Личного кабинета и электронной заявки владельца нет.

**Приёмка:** партия без обращения не получает фиктивного осмотра; кнопка недоступна ожидаемому/полностью отказанному поступлению и пользователю без основного права.

### FT-REP-02. Внешнее основание без местной ВСЭ

**Происхождение:** база PDR-004/007/013; D-18/44.

**Правило:** по принятой партии с применимой прежней ВСЭ можно сохранить местный повторный осмотр без местной первичной ВСЭ. В карточке осмотра различимы внешний источник и собственный специалист повторного наблюдения. Прежний протокол не копируется как новое исследование.

**Приёмка:** после сохранения осмотра внешней партии количество местных первичных ВСЭ не увеличилось; осмотр доступен из поступления.

### FT-REP-03. Ручной фактический остаток

**Происхождение:** база PDR-013; D-46; детализация R-15.

**Правило:** поле нового осмотра не подтверждает исходное количество как текущее автоматически; врач вводит/подтверждает наблюдённые массу, единицу и состав. Невалидные/отрицательные значения и дробные штуки отклоняются. Нулевой остаток можно сохранить как факт отсутствия продукции с пояснением «Остатка для исследования нет», без выполненных исследований/начислений и без фиктивного положительного результата; результат события в таком случае — «Осмотр продукции не выполнен: остаток отсутствует». Это предложенная детализация R-15.

**Приёмка:** уменьшение 100→60 кг не создаёт продажу на 40 кг; увеличение 60→70 кг не создаёт поступление; `abc` не подставляет 100.

### FT-REP-04. Результаты и стоимость исследований

**Происхождение:** база PDR-008/011/013; D-25/42; детализация R-11/15.

**Правило:** врач выбирает выполненные применимые исследования и их охват, вводит полные результаты. Не проводившееся не считается отрицательным и не оплачивается. При обязательности показателя для данного типа осмотра действует INPUT-02. Один выполненный показатель по трём тушам создаёт одну платную услугу осмотра на партию, а не три. Один показатель не дублируется в начислениях из-за нескольких результатов.

**Приёмка:** три исследованные туши и тариф показателя 50 ₽ дают 50 ₽ за осмотр; выключенный показатель не начисляется, незаполненный включённый отмечен ошибкой.

### FT-REP-05. Сохранение и повторное открытие

**Происхождение:** база PDR-013; S-12; детализация R-15.

**Правило:** сохраняются все поля события, основание, специалист, результаты и расчёт единым действием. Ошибка не создаёт неполный осмотр. Повторный клик не создаёт второй. После успеха доступна запись осмотра с фактическим временем и остатком. Промежуточный черновик осмотра отдельной функцией не требуется; несохранённый ввод защищается FT-COM-03.

**Приёмка:** обновление страницы/повторный вход показывают осмотр; две разные даты обращения владельца дают две отдельные записи, а один двойной клик — одну.

### FT-REP-06. Отрицательный осмотр не меняет первичную ВСЭ

**Происхождение:** база PDR-012/013; D-20.

**Правило:** любой результат осмотра сохраняется в нём. Первичная ВСЭ, внешний протокол и прежнее заключение не переписываются. Не появляется отдельный актуальный статус запрета реализации или автоматическая блокировка дальнейших действий/печати. Подпись решения врача в осмотре не является вычисляемым глобальным разрешением системы.

**Приёмка:** «Реализацию приостановить» видно при просмотре осмотра; первичная ВСЭ/её заключение прежние и доступны по принятой модели, отдельного стоп-статуса партии нет.

### FT-REP-07. Список, просмотр и исправление

**Происхождение:** база PDR-003/013; D-09/15; S-12; детализация R-06/15.

**Правило:** в контексте партии доступен список осмотров от новых к старым с датой, врачом, остатком, результатом и суммой; открывается полная запись. С основным правом можно исправить доступный осмотр коллеги перезаписью, без истории версий. При правке количества исследуемых туш цена показателя остаётся один раз за партию. Самостоятельное удаление осмотра и отдельный реестр осмотров не вводятся.

**Приёмка:** просмотр не меняет специалиста; исправление существующего осмотра не создаёт новый; возврат к партии сохраняет контекст.

### FT-REP-08. Удаление связанной местной ВСЭ

**Происхождение:** база PDR-013/014; D-22/44.

**Правило:** все осмотры, связанные с удаляемой местной ВСЭ, удаляются вместе с ней без архива/восстановления. Нельзя перекинуть их на новую ВСЭ с тем же номером. Внешняя ветка не имеет местной первичной ВСЭ, поэтому не получает искусственную команду такого удаления; отдельное удаление принятого поступления не добавляется.

**Приёмка:** удаление местной ВСЭ убирает её осмотры, но не осмотры другой партии с внешним основанием.
