# 06. Стоимость услуг, тарифы и нормы

## 1. Правила расчёта

База: PDR-008/011/014; D-25/27/32/42. Цены 100/50 ₽ ниже — только тестовые значения. Реальные данные должны прийти по INPUT-03, нормы — INPUT-02.

| Контекст | Формула | Единица |
|---|---|---|
| Первичная ВСЭ, показатель `i` | `Si = Ti × Ni`, где `Ni` — число действительно исследованных туш по показателю | Исследованная туша; точное соответствие типу части проверяет INPUT-03 |
| Повторный осмотр, показатель `i` | `Si = Ti`, если показатель проведён хотя бы по одной части данной партии; иначе 0 | Партия за данный осмотр |
| Сверка: идентификация продукции | `S = T × N` по фактически оказанным единицам услуги | В исходном мясном процессе — принятые идентифицированные туши; продуктивная единица/охват требуют INPUT-03 |
| Сверка: оценка транспорта | `S = T × NТС` по реально оценённым ТС | ТС; прицеп не объявляется отдельной услугой без прейскуранта |
| Итог операции | Сумма начисленных строк этой операции | Рубли, с копейками |

**Детализация R-12/17:** каждая услуга сверки, первичной ВСЭ и повторного осмотра имеет свой контекст; одинаковое название не даёт права дважды начислить одно выполненное действие. Отдельное платное действие в другом контексте допускается только если оно явно есть в утверждённом прейскуранте. Сводка партии может суммировать уже сохранённые операции, показывая их отдельно, но не создаёт новые начисления.

## 2. Требования к расчётам

### FT-CAL-01. Первичный показатель по исследованным тушам

**Происхождение:** база PDR-011; D-27.

**Правило:** количество услуги определяется по отдельным принятым тушам с полным фактически проведённым показателем. Наличие туши в партии без исследования не начисляет услугу. Массовое заполнение не уменьшает множитель. Для иных учётных частей коэффициент/единица не угадывается: применяется подтверждённая строка INPUT-03.

**Приёмка:** четыре туши × 100 ₽ = 400 ₽; исследованы только три — 300 ₽; одна строка массового ввода четырём по-прежнему 400 ₽.

### FT-CAL-02. Повторный показатель за партию

**Происхождение:** база PDR-011/013; D-42.

**Правило:** каждый выполненный показатель тарифицируется один раз за партию в пределах одного осмотра. Число результатов/туш/повторных замеров не создаёт повторных строк той же услуги внутри осмотра. Следующий самостоятельный осмотр — отдельное событие с отдельным расчётом.

**Приёмка:** три туши с одним показателем по 50 ₽ дают 50 ₽; два разных выполненных показателя по 50 дают 100 ₽; следующий осмотр снова рассчитывается отдельно.

### FT-CAL-03. Сверка и транспорт

**Происхождение:** основа PDR-011, S-01/02/10; детализация R-17; INPUT-03.

**Правило:** начисляются только оказанные услуги по подтверждённым единицам прейскуранта. Врач видит наименование, контекст, количество, единицу, тариф и сумму. Недоставленные части и отсутствующее ТС не создают услугу; физически осмотренные, но возвращённые части учитываются только если утверждённый прейскурант определяет их как оказанную услугу. Нельзя молча выбрать «по принятому» либо «по доставленному» при отсутствии такого определения.

**Приёмка:** при частичном отказе количество идентификаций соответствует утверждённому охвату, а не автоматически документальным тушам; перечень исходных выполненных услуг виден врачу.

### FT-CAL-04. Денежная точность

**Происхождение:** детализация R-17 на основе PDR-011; DETAIL-01.

**Правило:** тариф неотрицательный, до двух знаков копеек; пусто не равно нулю. Нулевой тариф допустим только как явно заданная нулевая цена. Итог строки округляется до копейки обычным правилом половина вверх; общий итог — сумма округлённых строк, без скрытой иной формулы. Нечисловые значения/отрицательные цены отклоняются. Нет двоичных артефактов вида 299,999999 ₽. При дробной единице услуга и точность количества берутся из прейскуранта.

**Приёмка:** 3 × 100,10 ₽ = 300,30 ₽; 0 ₽ сохранён как явная цена, пустая цена отмечена как отсутствие данных.

### FT-CAL-05. Прозрачный расчёт до сохранения

**Происхождение:** база PDR-011; S-02/03/10; детализация R-12.

**Правило:** в форме видны фактически заполненные исследования/услуги, их охват, тарифы, суммы и итог. При неполном вводе показывается предварительный расчёт, не полное начисление за неготовые результаты. Изменение результата или охвата обновляет соответствующие строки по правилам текущей операции. Общая сумма не редактируется свободно, ручные скидки/доплаты не добавляются.

**Приёмка:** добавление результата четвёртой туше увеличивает первичную строку с трёх до четырёх; то же изменение повторного осмотра не увеличивает его единицу «партия».

### FT-CAL-06. Сохранённые тарифы и суммы

**Происхождение:** база PDR-011; D-25.

**Правило:** успешное сохранение рабочей записи закрепляет каждую строку: наименование/контекст, единицу, количество, применённый тариф, сумму и общий итог. Последующие просмотр/печать/изменение текущего справочника не заменяют эти данные. Сохраняется актуальный расчёт записи без истории прежних версий ВСЭ.

**Приёмка:** старая ВСЭ и старый осмотр после смены цены со 100 на 150 ₽ сохраняют прежние суммы; новая операция использует 150 ₽.

### FT-CAL-07. Намеренное изменение услуг старой записи

**Происхождение:** база PDR-011; D-25; DETAIL-02; детализация R-12.

**Правило:** неизменённые услуги сохраняют цену. При изменении числа исследованных туш существующего показателя его закреплённый тариф умножается на новое количество; у повторного показателя остаётся один тариф за партию. Удалённая услуга исключается из актуального расчёта. Вновь добавленный показатель получает текущий тариф с явной пометкой. Для удалённой из записи, затем заново добавленной и сохраняемой как новая услуги действует текущая цена; до сохранения отмена правок возвращает прежний расчёт. Нет команды скрыто пересчитать всю запись по сегодняшним тарифам.

**Приёмка:** в старой ВСЭ 4 × 100 ₽; после изменения справочника на 150 и намеренного уменьшения охвата до трёх сумма 300 ₽, а новый другой показатель берёт текущую цену. Поведение R-12 подлежит обзору владельцем.

## 3. Справочники

### Состав справочных данных

| Справочник | Минимум данных |
|---|---|
| Тарифы первичной ВСЭ | Показатель/услуга, применимость продукции, единица, цена в рублях |
| Тарифы повторного осмотра | Показатель, применимость, единица «партия за осмотр», цена |
| Услуги сверки и транспорта | Услуга, что считается оказанным, единица, охват принятого/доставленного/осмотренного, цена |
| Нормы и методика | Полная строка INPUT-02: тип/единица, обязательность/условие, критерий и границы, источник/проверяющий |

Не требуется универсальный конструктор правил или отдельный механизм публикации версий. Содержание должно позволять реализовать проверенные таблицы применимости. Создание дополнительной записи внутри существующего справочника входит в редактирование; произвольные новые типы справочников не создаются пользователем.

### FT-CAL-08. Просмотр и изменение справочников

**Происхождение:** база PDR-003/011; S-09/10; детализация R-17.

**Правило:** доступные мясные справочники видны по предметному доступу; изменение только с правом редактирования. Обязательные значения и типы проверяются, недопустимый диапазон `нижняя > верхняя` отклоняется. Критерий явно различает включённую/исключённую границу, односторонний предел и качественные значения. Сохранение не считается методическим утверждением непроверенного содержимого. Продуктивная первоначальная загрузка выполняется ответственными по INPUT-02/03, а не обязательным заполнением каждым врачом при первом входе.

**Приёмка:** врач без права видит применённую норму/цену, но не меняет справочник; некорректные границы не сохраняются; применимость свинины не копируется автоматически всем видам мяса.

### FT-CAL-09. Сохранение оценки при смене нормы

**Происхождение:** база PDR-008/011; D-32.

**Правило:** норма из актуального справочника используется новым результатом по правилам FT-VSE-11. В сохранённой записи остаются её применённый критерий, единица, оценка и результат. Удаление текущей нормы не ломает чтение старых оценок и расчётов; история справочника для этого не требуется.

**Приёмка:** изменение границы так, что прежнее значение стало бы нормальным, не перекрашивает старую красную оценку; новая ВСЭ оценивает по новой применимой строке.

### FT-CAL-10. Нет нормы, цены или подтверждённой конфигурации

**Происхождение:** база PDR-008/011/015; A-11/17; INPUT-02/03; детализация R-17.

**Правило:** отсутствие настройки показано явно. Не подставляются демонстрационные значения, нулевая цена и «норма». Факты можно сохранить в черновике; завершение операции с обязательным расчётом/оценкой недоступно до заполнения необходимой конфигурации. Врач без права настройки видит, что требуется обратиться к уполномоченному сотруднику, а не застревает в обязательной форме редактирования справочника. Отсутствие необязательного неприменяемого показателя не блокирует остальные операции.

**Приёмка:** пустой тариф выполненного показателя даёт понятную причину невозможности финального расчёта; черновик не потерян; явно заданный 0 проходит отдельно.

### FT-CAL-11. Удаление позиции или справочника

**Происхождение:** база PDR-003/011/014; D-25/32; DETAIL-02; детализация R-18.

**Правило:** отдельное право удаления позволяет после подтверждения удалить доступную позицию/содержимое справочника из выбора для новых операций. Сохранённые рабочие расчёты и оценки остаются воспроизводимыми из своих записей. Использование старой позиции не запрещает её удаление автоматически, не удаляет ВСЭ и не обнуляет цену. При удалении обязательной настройки предупреждение описывает, какие новые операции станут недоступны по FT-CAL-10. Не требуется сохранять скрытые версии удалённого справочника. Технические связи выбирает ADR.

**Приёмка:** после удаления старые 400 ₽/красная оценка прежние; новый показатель без настройки не завершается; пользователь с правом удаления, но без редактирования не получает неявное право менять цену.

### FT-CAL-12. Нет расчёта оплаты

**Происхождение:** база PDR-001/011; D-17/25/27/42.

**Правило:** сумма услуг означает начисленную стоимость, не факт внесения денег. Нет признаков «оплачено» на основании сохранения, платёжной формы, кассового чека или бухгалтерского проведения. Внешняя первичная ВСЭ не начисляется как проведённая нашей лабораторией; сверка и собственный повторный осмотр рассчитываются в своих контекстах.

**Приёмка:** заключение/ВСЭ не получают фиктивное подтверждение оплаты; внешняя партия без собственного исследования не получает местную первичную стоимость.
