# Проверка выпуска 2.0

Дата: 09.11.2026. Проверки подготовки документации завершены; выпуск передаётся владельцу для содержательного обзора.

## Выполнено

- Архив vse-product-foundation-v1.9.zip побайтно сопоставлен с product-design-records/v1.9 по SHA-256 всех файлов: различий нет. Основные PDR/каталог/решения, исторические уточнения, прежние требования и макеты использованы с явным приоритетом.
- Оригинальные источники PRD и прежних FT включены без изменений. Контрольные суммы — sources-manifest.json; повторная проверка всех 41 оригинальных файлов выполнена.
- 23 страницы открыты в установленном Chrome через Playwright: прочитаны заголовки, отображаемый текст и поля; исключений JavaScript при этих открытиях не зарегистрировано. Наблюдения — sources/mockup-observations.json. Это обзор экранов, не полный регрессионный тест.
- Проверены 81 уникальный идентификатор FT, наличие основания/правила/приёмки у каждой карточки, реестр, 82 поля CHK/VSE, судьба всех 87 прежних требований, индивидуальная трассировка 101 SC и покрытие 21 PDR.
- Проверены локальные Markdown-ссылки и отсутствие незакрытых продуктовых вопросов; решения закрыты O-01–13. O-12 закрепляет test profile, O-13 — обязательную реализацию гашения при запрете агентам проверять её живым вызовом.
- Независимый builder check выявил тупик сохраняемого черновика; владелец исключил черновики O-09. Повторная проверка не выявила новых существенных замечаний. Подробности — review-findings.md.
- После O-12/O-13 проверено, что test read использует `productType=1` и source `name`, а гашение обязательно реализуется до real transport/UI enabled-state. Все шесть сценариев проверяются fixtures/spy; агент не выполняет живой write для доказательства кода.
